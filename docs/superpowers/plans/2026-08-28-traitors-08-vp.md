# The Traitors — Plan 8: The Visual Layer

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a Traitors season watchable — screens with the show's own visual identity, the conclave as the signature piece, and a text backlog that retranscribes every word of it.

**Architecture:** The engine and its export are complete (Plans 1–7, 448 tests). Screens live in a new `js/vp-tr/`, one file per screen, registered into `buildVPScreens()` in `js/vp-screens.js` the way `js/vp-bb-sig/` already registers Big Brother's signature screens. Navigation, reveals and particles come from `js/vp-ui.js` and are not reimplemented. **Task 1 builds the conclave alone, end to end, and its approved look is the language every later screen is built against.**

**Tech Stack:** ES modules, no build step. Inline SVG for visual elements. vitest for the invariants; the look is judged by rendering it.

**Spec:** `docs/superpowers/specs/2026-08-25-traitors-design.md` §9 (VP), and §9.1 (the observer contract) in particular.

**Prior plans:** 05 (scene selection), 06 (missions/powers/endgame), 07 (export). Their appended lesson sections carry findings that bind this plan.

## How this plan is run differently, and why

Plans 1–7 leaned on mutation testing, control arms and 1,200-season sweeps, because **engine defects are invisible** — a bed count wrong on every firing, a guard that never matched, a band measuring survivors instead of writes. None of that is visible by looking.

**Screen defects ARE visible by looking.** So the loop here is: build → render → screenshot → the human judges it → iterate. No mutation testing on CSS.

**Three things keep hard guards anyway, because they are invisible:**

1. **The conclave must never be shown to the audience as public.** Murder ballots sit in `votes[]` beside banishment ballots, distinguished only by `channel`. Any screen that does not filter `channel === 'banishment'` renders the show's central secret. Plan 7 already found this happening in the social feed.
2. **No screen may print another show's vocabulary.** The project's central bug class. `tests/show-vocabulary.test.js` now runs in both directions and `EXCLUSIVE` was extended in Plan 7 — keep it extended.
3. **The observer contract.** Every builder takes `rpBuild*(ep, observer)`. Three layers must be renderable: what a given player knows, what the Faithfuls collectively believe, and what is true. **Deciding it now is free; retrofitting it across every screen later is a rewrite.**

## Global Constraints

- **Overdrive is the baseline** (project CLAUDE.md). Unique CSS class prefix per screen. At least two fonts. `max-width:1100px;margin:0 auto` — never full-screen. Phase-specific backgrounds. `@media(prefers-reduced-motion:reduce)` on every animation. **CSS-only animated icons via an `_icon(type)` helper — no emoji.** Persistent background animation fitting the theme. Sticky reveal controls with a live counter and `scrollIntoView({behavior:'smooth',block:'center'})`.
- **SVG for visual elements, never CSS div hacks.** CSS is for layout and simple geometric indicators only.
- **DOM-only updates on reveal.** Never rebuild the page — `_reapplyVisibility(suffix, upToIdx, total)` loops 0→idx, adds the visible class, updates the counter, dims the controls. Required element IDs per the CLAUDE.md pattern. Save and restore `scrollTop`.
- **`_tvState[key]` with `idx:-1` for click-to-reveal.** The sidebar rebuilds on every reveal via `innerHTML` replacement by ID, is gated by `_tvState` so it never spoils ahead, and stores phase data on `window` rather than globals that get overwritten. Called from BOTH `revealNext` AND `revealAll`.
- **`renderVPScreen` wipes reveal state on every paint** — inline handlers bake their targets. Known gotcha, see `project_tvstate_wipe` in the repo's memory notes.
- **`<script>` tags in `innerHTML` do not execute.** Set `window` data in the build function.
- **Text backlog is a complete retranscription of every VP narration**, placed before `_textCampPost` in `generateSummaryText()`.
- **NEVER `git stash`, never `reset --hard`, never `git add -A`.** Stashes are per-repository; this worktree shares a stack with live uncommitted work on `main`.

## Facts the implementer needs and cannot infer

- Screens register in `buildVPScreens()` (`js/vp-screens.js:13506`) as `vpScreens.push({ id, label, html })`. Big Brother's signature screens in `js/vp-bb-sig/` are the structural precedent; **the visual language must not be borrowed from them** — the anti-reuse rule is explicit in CLAUDE.md.
- The export shape (Plan 7): one `votingHistory[]` row per episode, every ballot carrying `channel` (`banishment` / `banishment-revote` / `murder`). `roundExits()` and `publicBallots()` in `js/shows.js` are the rules — use them, do not re-derive.
- Traitors has TWO exit verbs, **banished** and **murdered**, from the registry. Nothing writes either as a literal.
- The engine's measured shape, for sizing screens: ~20 cast, ~9 episodes to the endgame, mean 1.29 extra endgame tables, Faithfuls win ~54.6%, a Traitor takes everything ~54.5% of the time, betrayal 0% at fields of 7+ and 88.6% at a field of 3.
- `gs.tr.notoriety` (spectacle) and `gs.popularity` (affection) are separate ledgers — Plan 7 §Task 5. **Nothing outside `js/tr/crowd.js` may name either**, so a screen reads them through the export, not from `gs`.
- Baseline: `npx vitest run tests/tr-*.test.js` → **448 green**; `audit:tr-castle` 5; `show-vocabulary` + `show-list-duplication` 47.

## Task 1 done — the conclave, and four fixes to the shared language

its own mutation. The render matches the approved mockup; three deliberate departures are

**Three of the build's own guards were VACUOUS as first written** and were caught only by
running their own mutations, not by the green suite: a `'\b'` that was U+0008 so every negative
assertion passed for free; a guard asserting the screen against the very list it was built

this repo has shipped before.

### The four fixes, and what they taught

1. **The sticky sidebar had TWO causes.** `.cv-shell{overflow:hidden}` kills `position:sticky`
   for descendants -- necessary but not sufficient. `.cv-side` was ALSO exactly as tall as its
   grid (3946px both), so sticky had zero range. Now the clip lives on a dedicated `.cv-scenery`
   layer (deliberately with no `z-index`, or the grain drops below the body) and
   `#cv-sidebar-inner` is the sticky element. Measured at scroll 3000: built screen −2383 ->
   **+56**; mockup −2455 -> **0**. **The approved mockup carried the same defect** -- fixed
   there too, because it is the contract Tasks 2-5 build against.
2. **The irony gutter goes sparse, not repeating.** A beat with no scene gets an empty cell and
   no timestamp. Repetition reads as a bug; a quiet minute is honest.
3. **One vocabulary list, and it caught a real defect on its first run.** The two lists were
   merged into `tests/helpers/show-vocabulary.js` -- and the conclave was immediately found
   saying **"house" three times**, Big Brother's word, which the restated copy had never been
   forbidding. Two copies of one rule, and the copy that mattered was the weaker one.
4. **Avatar lighting is a CONCLAVE treatment, not the shared helper's.** `_portrait()` is
   neutral and exported for Tasks 2-5; every lighting declaration is qualified by `.cv-lit`.
   A helper that bakes in one screen's atmosphere forces every later screen to fight it or
   wear it. Same principle as vocabulary coming from the registry: **the shared thing stays
   neutral and each screen opts into its own character.**

## Task 2 done — the ring, and three fixes with measurements

531 tests green. `js/vp-tr/round-table.js`, 40 guards. The user approved the ring and named the
reference himself: **Danganronpa's class trial** — a room of people all visible at once arguing
about which of them is lying. What transferred was the GRAMMAR, not the styling: everyone on
screen the whole time, each with a station that changes as the scene runs, arguments crossing
the space as chords from voter's seat to named seat, and **the gone still present as marked
seats** — banished and murdered rendered differently, because this show has two doors out.

### `transform-origin` on SVG needs `transform-box: fill-box`

The flame "moved weirdly" and the root cause was not easing. **`transform-origin` on an SVG
element resolves against the VIEW BOX, not the element's own box**, unless `transform-box:
fill-box` is set. So `50% 92%` pivoted each candle around a point roughly a thousand units
below its own wick, and every flame swung on an enormous invisible arm.

Measured max drift of each flame's centre: hall **125.6px x / 145.2px y -> 1.2px / 1.2px**;
turret lantern -> 1.7 / 2.0px.

Four causes were suspected and all four were true, but that one dominated. The others, all
worth keeping as flame rules: anchor at the base, layer shape/opacity/halo on **coprime
periods** so the cycle never visibly repeats, put the flicker on LIGHT rather than
displacement, keep amplitude small (skewX <= 2.3 deg), and stagger per-flame delays so 56
candles share no beat.

### Even-angle spacing was the overlap, not the ellipse

Task 2 concluded the fix needed "an ellipse taller than the screen can give". Wrong: equal
angles cover unequal arc lengths on any non-circular ellipse, so seats crowd where the curve is
steepest. `_seatAt` now walks a cumulative arc-length table (1024 samples, agreeing with 20,000
to 0.1px). Measured at the largest real cast, **which is 24** — the ring is `gs.tr.castOrder`,
living plus memorial, never shrinking, uncapped:

| | min centre-to-centre | min clearance |
|---|---|---|
| before | 41.8px | **-0.5px (overlapping)** |
| after | **72.7px** | **+25.8px** |

No portrait shrinking was needed. **Measure the geometry rather than eyeballing it** — the fix
was verified off real rendered markup in CSS pixels, not by looking at a screenshot.

### The first-paint pattern for Tasks 3-5

`conclave.js` emitted a bare `cv-beat` and relied on `_reapplyVisibility` firing from a click,
so the screen was **blank until the viewer pressed something**. `round-table.js` did NOT have
the defect — it bakes visibility in from `st.idx` at emit time with a comment saying why.
**Copy the Round Table's pattern.**

### Vacuous guards, still one per task

Task 2 shipped two, both "redundancy hiding a dead guard" — dropping `publicBallots()` changed
nothing because the next line re-filtered on the same field, and neither endgame reveal-lock is
individually catchable because each covers the other. The fix round shipped one more:
`beats.every(...)` over an EMPTY list, because a `\d` was eaten by a heredoc so the regex
matched nothing. Same family as the U+0008 trap — **an escape eaten in transit leaves a guard
that passes for free.** Caught by its own mutation; fixed with a count assertion first.

### Carried

- The arc table uses the design-box ellipse, not the CSS-rendered one, so spacing is even to
  ~8%. Closing that couples geometry to two CSS constants.
- `_ARC_N` and the `41.7%` padding are eyeballed constants.
- Near-row name plates sit under the fixed controls in a full-height capture — **Task 7**.
- A backtick inside a CSS comment in these template-literal stylesheets is a parse error.

### Two guard techniques worth reusing

**1. Mutate a gate in BOTH directions.** The relic gate was mutated to `known = true` (killing
the non-witness arm) AND `known = false` (killing the entitled arm), because **neither
direction alone catches a gate stuck in the other position.** A one-way mutation on a two-state
gate proves half of it.

**2. Refusing to write a guard is sometimes correct.** The blocked-murder branch is written and
deliberately UNGUARDED: across twenty seeded seasons it never fired once, because a Shield only
blocks when the pact happens to name its holder. **A guard on an unreachable state is a vacuous
guard** — the honest move is to say so rather than ship a test that passes for free.

And the trap avoided on purpose: `goneBefore` excludes tonight's own exits **specifically so**
the board's `roundExits()` call is load-bearing. Folding them in would have left that filter
unable to change the answer — this plan's recurring vacuous shape.
